Your Minecraft server with friends, set up in 5 minutes

Setting up a server from scratch takes hours of plugins, permissions and config files. Here you pick four things, download a .zip and upload it to your host. Done.

  • Geyser + FloodgateMobile, console and Windows (Bedrock) players share the same world as PC players, no Java account needed.
  • ViaVersionIf someone's Minecraft updates, they can still join.
  • EssentialsXHomes, /tpa between friends, /back when you die and private messages.
  • LuckPermsPermissions are already set: every player can use their commands from minute one.
  • CoreProtectIf someone breaks or steals something, you see who did it and undo it with one command.

Customise it

Plugins are downloaded from their official site right then: you always get the latest version.

How to upload it to your host

  1. Pick Paper 26.1.2 as the server type in your host's panel.
  2. Start it once and stop it. That creates its folders and accepts the EULA.
  3. Upload the .zip to the main folder and extract it there. If it asks whether to replace files, say yes.
  4. Start it. PC players join with the IP; Bedrock players with the same IP and the same port.
  5. Make yourself admin: in the panel's console type op YourName.

Inside the zip there's a README.txt with the commands, how to undo griefing and how to make the server friends-only.

Frequently asked questions

Is it free?

Yes, all of it. No sign-up, no email.

Where do the plugins come from?

From their official site (Modrinth and GeyserMC). Your browser downloads them when you press the button and builds the zip on your computer: this site doesn't host or modify any plugin.

Why Paper 26.1.2 and not the latest version?

Because it's the newest one where every plugin is tested and works. With ViaVersion, people on an updated game can still join, so you won't notice a thing.

Does it work on any host?

On any host that lets you run Paper and upload files, which is nearly all of them. If your host gives you a separate Bedrock port, the README explains which line to change.

I uploaded the zip and nobody can join

The zip has its own server.properties. Almost every panel puts your port back automatically on start; if yours doesn't, open that file and add server-port= with the port your host gives you.

What if I want to run it on my PC?

That works too: download Paper 26.1.2 from papermc.io, put it in a folder, extract the zip next to it and start it. Your PC has to stay on for the others to play, though.
